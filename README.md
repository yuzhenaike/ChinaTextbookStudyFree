# ChinaTextbookStudyFree

面向手机端的**教材电子课本 + 同步习题**导航索引站点，优先整理国内网络可直连的官方公开来源。

## 导航内容

- **看教材**
  - 人教社官方电子版教材（人教版，免登录）
  - 国家中小学智慧教育平台 · 电子教材（小初高，官方免费；游客可浏览公开课本，部分资源需登录）
  - 国家平台 · 课程教学（同步视频与配套资源）
  - 高教社新形态教材网（大学教材）
- **找习题**
  - 国家平台 · 基础性作业与习题库（同步题、分层习题、单元 / 期末卷）
  - 学科网（同步练习与试卷，部分免费、有下载额度，部分付费）
- **补充来源**：GitHub 开源教材仓库（国内部分网络下访问可能不稳定）

## 合规与版权说明

- 本仓库**仅包含导航网页**，不存储、不上传、不分发任何教材或习题文件副本。
- 页面外链均指向公开来源；教材与习题版权归原出版方所有，请仅限个人学习使用。
- 第三方平台部分资源需登录，个别内容可能收费，以对应平台页面为准。
- 如认为某一导航链接涉及版权问题，可联系仓库维护者移除对应链接。

## 本地预览

无需构建工具，直接用浏览器打开 `index.html`，或在本目录运行：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```

## 部署（GitHub Pages）

1. 将本目录推送到 GitHub 仓库 `ChinaTextbookStudyFree` 的 `main` 分支。
2. 仓库 **Settings → Pages**，Source 选择 `main` 分支 / 根目录（`/root`）。
3. 发布后访问 `https://<用户名>.github.io/ChinaTextbookStudyFree/`。

> 若 `github.io` 在国内网络下打不开，可通过 jsDelivr CDN 直链访问本仓库页面：
> `https://cdn.jsdelivr.net/gh/<用户名>/ChinaTextbookStudyFree@main/index.html`
